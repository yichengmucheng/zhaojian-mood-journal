# 照见 · 情绪日记与自我关怀

一个面向年轻人的本地优先情绪记录 Web 应用。用户可以快速记录情绪、强度、触发情境和身体感受，查看一周趋势与高频线索，并立即开始呼吸、白噪或轻运动练习。

## 产品原则

- 30 秒完成一次记录，降低表达门槛
- 把“情绪”与“触发情境 / 身体感受”分开记录，减少自我评判
- 洞察只展示可解释的统计，不做医学诊断
- 无需登录，数据只保存在浏览器 `localStorage`
- 首次访问包含演示数据，便于快速体验完整流程

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
